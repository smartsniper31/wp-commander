# 📖 Guide Utilisateur WP Commander

## 🏠 Tableau de Bord

### Vue d'ensemble
- **Statistiques globales** : Sites actifs, connectés, santé moyenne
- **Sites récents** : Accès rapide aux sites utilisés récemment
- **Actions rapides** : Sync, ajout de site

### Gestion des Sites
1. **Ajouter un site**
   - Tapotez ➕
   - Remplissez nom, URL, clé API
   - Test de connexion automatique

2. **Vue détaillée d'un site**
   - Tapotez sur une carte de site
   - Statistiques en temps réel
   - Santé du site
   - Commentaires en attente

## 📊 Fonctionnalités

### Monitoring de Santé
- **Score de santé** : 0-100 points
- **Problèmes détectés** : Sécurité, performance, mises à jour
- **Recommandations** : Actions pour améliorer le score

### Gestion des Commentaires
- **Vue modération** : Commentaires en attente, approuvés, spam
- **Actions rapides** : Approuver, supprimer, marquer comme spam
- **Filtres** : Par statut, date

### Actions Rapides
- **Vider le cache** : Purge tous les caches WordPress
- **Mode maintenance** : Active/désactive le mode maintenance
- **Optimisation BDD** : Nettoie et optimise la base de données

## ⚙️ Paramètres

### Apparence
- **Thème** : Clair/Sombre/Auto
- **Langue** : Français/Anglais
- **Animations** : Activer/désactiver

### Notifications
- **Alertes santé** : Notifications pour problèmes critiques
- **Nouveaux commentaires** : Alertes pour commentaires en attente
- **Synchronisation** : Notifications de sync complète

### Sécurité
- **Verrouillage app** : Code PIN ou biométrie
- **Chiffrement** : Données locales chiffrées
- **Déconnexion auto** : Après inactivité

## 🔄 Synchronisation

### Manuel vs Automatique
- **Manuelle** : Pull-to-refresh ou bouton sync
- **Automatique** : Toutes les 15 minutes
- **Intelligente** : Seulement si données périmées

### Données Synchronisées
- Statistiques du site
- Santé et performance
- Commentaires
- Informations du site.
