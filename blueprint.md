# Project Blueprint

## Overview

This is a Flutter application designed to manage WordPress sites. It allows users to view site information, statistics, and manage comments.

## Features Implemented

*   **Site Management:**
    *   Add, edit, and delete WordPress sites.
    *   Securely stores site credentials (URL and API key).
*   **Dashboard:**
    *   Displays a list of configured sites.
    *   Shows a summary of pending comments for each site.
*   **Site Details:**
    *   Shows detailed statistics for a selected site, including total posts, pages, comments, and users.
*   **Comment Management:**
    *   View comments for a site.
    *   Approve, delete, and mark comments as spam.

## Design and Style

*   **Architecture:** The app follows a clean architecture pattern with a separation of concerns into `data`, `domain`, and `presentation` layers.
*   **State Management:** `flutter_riverpod` is used for state management.
*   **UI:** The UI is built with Flutter's Material components.
