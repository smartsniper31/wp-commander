## ✨ Features

- 📊 **Real-time Dashboard** - Monitor all your sites at a glance
- 🏥 **Site Health Monitoring** - Comprehensive health checks and scoring  
- 💬 **Comment Management** - Moderate comments on the go
- ⚡ **Quick Actions** - Cache clearing, maintenance mode, optimization
- 🔒 **Enterprise Security** - Secure API communication and encryption
- 🌙 **Dark/Light Theme** - Beautiful UI with theme support
- 🔄 **Real-time Sync** - Always up-to-date information

## 🛠️ Quick Start

### WordPress Plugin
1. Upload `wordpress_plugin/wp-commander` to your WordPress site
2. Activate the plugin
3. Get your API key from Settings > WP Commander

### Mobile App
1. Open the Flutter app
2. Add your site with URL and API key
3. Start managing your site!
